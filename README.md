# Netflix Data Cleaning Project

## 📌 Overview
This project focuses on cleaning and preprocessing the **Netflix Movies & TV Shows dataset** using Microsoft Excel. The objective was to transform raw and inconsistent data into a structured, analysis-ready dataset by applying professional data cleaning techniques commonly used in real-world analytics workflows.

---

## 🎯 Objectives
- Handle missing values
- Remove duplicate records
- Standardize inconsistent text formatting
- Validate data types
- Improve overall dataset quality
- Maintain separate raw and cleaned datasets

---

## 🛠 Tools Used
- Microsoft Excel
- Conditional Formatting
- Filters & Freeze Panes
- Data Validation
- Excel Functions:
  - `TRIM()`
  - `PROPER()`
  - `UPPER()`

---

## 📂 Dataset
Netflix Movies and TV Shows Dataset

---

## 🔍 Data Cleaning Steps Performed

### 1. Imported Raw Dataset
- Loaded the CSV dataset into Microsoft Excel
- Verified column headers and formatting

### 2. Applied Filters & Freeze Panes
- Enabled filters for easier exploration
- Used Freeze Panes to lock header rows

### 3. Handled Missing Values
- Identified blank cells using filters and conditional formatting
- Reviewed missing values based on column context

### 4. Removed Duplicate Records
- Detected and removed duplicate entries
- Maintained backup copies before modification

### 5. Standardized Text Formatting
- Removed extra spaces
- Corrected inconsistent naming formats
- Applied text-cleaning functions

### 6. Validated Data Types
- Checked date formats
- Corrected numeric inconsistencies
- Verified categorical data consistency

### 7. Added Data Quality Notes
- Created a `Data_Quality_Notes` column
- Documented observations related to dataset quality

### 8. Created Cleaned Dataset
- Generated a separate cleaned dataset
- Prepared data for future analysis tasks
